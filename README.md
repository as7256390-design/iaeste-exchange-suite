# IAESTE Exchange Operations Suite

A self-contained web application for IAESTE exchange operations, multi-year activity report analysis, intelligent offer grading, and bilateral country strategy planning.

## Features
- **Activity Report Analyzer**: Historical exchange metrics and multi-year trend visualisations.
- **Intelligent Offer Grader**: Automated offer evaluation and pre-trained classification models.
- **Country Exchange Strategies**: Strategic exchange guides, key bilateral country targets, and priority tracking.
- **Offline PWA Support**: Installable as a Progressive Web App on mobile (iOS / Android) and desktop for offline availability.

## Running Locally
Simply open `index.html` in any modern web browser or serve via:
```bash
python3 -m http.server 3456
```
Or run `./start_network_share.sh` for multi-device local network sharing.
